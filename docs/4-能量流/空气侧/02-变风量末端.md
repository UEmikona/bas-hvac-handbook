# 变风量末端（VAV）

> **一句话概括：** 变风量末端（VAV，Variable Air Volume）根据各房间的实际需要，调节送入房间的风量。它让空调系统从"一直满负荷送风"转为"按需送风"，是空气侧节能的重要环节。

## 学习目标

- 理解 VAV 与定风量系统的区别
- 说清最小风量、最大风量与再热的含义
- 理解为什么 VAV 需要设定最小风量，以及它与新风量的关系
- 能说出 VAV 控制器的主要监控点及其作用

## 1. 核心概念

**VAV 末端：** 安装在风管末端的风量调节装置，包含风阀、风量传感器和控制器。

**定风量系统（CAV）：** 每个房间的送风量固定不变，靠调节送风温度来满足需求。

**变风量系统（VAV）：** 每个房间的送风量可以变化，靠调节风量来满足需求。

**最小风量：** VAV 末端允许的最低送风量。设定最小风量的原因后面会讲。

**再热：** 在送风进入房间前，对空气进行加热，用于防止房间过冷。

## 2. 为什么这样设计

在一栋楼中，各房间的负荷差异很大。朝西的会议室下午很热，北侧的办公室可能很凉，有人的房间需要的新风多，无人的房间几乎不需要。

如果所有房间都按最大负荷送风，既浪费风机能耗，又会造成过冷或过热。VAV 的思路是：**谁需要多少，就送多少。** 风量减少时，风机的能耗也随之下降。

由于风机功率随风量的立方变化（前面的相似定律），风量减少 20 %，风机功率大约下降 49 %。这就是 VAV 节能效果显著的原因。

💡 **类比：** VAV 像一座大楼的电灯分区控制。不是所有灯都全开，而是根据每个区域是否有人、光线是否充足来决定开哪几盏。VAV 调节的是"风"，但道理相同：按需供给，避免浪费。

## 3. 系统组成与原理

### 3.1 VAV 末端的组成

| 部件 | 作用 |
| --- | --- |
| 风阀 | 调节流经末端的风量 |
| 风量传感器 | 测量实际风量，用于闭环控制 |
| 房间温度传感器 | 检测房间温度，决定需要多少风量 |
| 控制器与执行器 | 根据偏差调节风阀开度 |
| 再热盘管（可选） | 在需要时加热送风 |

### 3.2 最小风量为什么需要设定

最小风量不能设为零，主要原因有两点：

1. **室内空气质量：** 房间需要持续的新风，以稀释二氧化碳和污染物。如果风量为零，即使是无人房间，空气质量也可能变差。
2. **气流组织：** 风量太小时，气流不足以混合空气，房间内可能出现温度分层，使人感到不舒适。

> [!IMPORTANT]
> 最小风量应至少满足新风量的要求，并且通常还需要满足气流组织的要求。最小风量过高会削弱节能效果，过低则会影响室内空气质量，必须在设计和调试中综合确定。

### 3.3 再热的作用与代价

当房间需要的风量已降到最小值，但房间仍然过冷时，就需要通过再热来补偿。再热会消耗额外的能量，因此应尽量避免。

这也是 VAV 控制中需要重点考虑的问题：**减少同时制冷和再热的情况**。如果一边冷却送风、一边又加热送风，就是能源的浪费。

## 4. 控制逻辑

一个典型的 VAV 控制过程如下：

1. 房间温度传感器测得室内温度，与设定值比较。
2. 若室温高于设定值，需要增加送风量，控制器加大风阀开度。
3. 风量传感器反馈实际风量，控制器据此修正阀门位置，使实际风量接近目标风量。
4. 若室温低于设定值，且风量已降到最小值，则启动再热。
5. 若房间无人，可以切换到更低的设定值或更低的最小风量（非占用模式）。

**分级控制思路：** 通常先调节风量，风量达到极限后再考虑再热。这样可以减少不必要的加热，保持节能。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 房间温度长期偏高 | 风阀未开足、风量传感器故障、送风温度不足 | 检查风阀反馈，核对风量读数，检查送风温度 |
| 房间温度忽高忽低 | 控制参数过于激进、风量传感器信号异常 | 检查控制参数，观察风量与温度的历史趋势 |
| 同时出现制冷和再热 | 控制逻辑中缺少互斥或分级保护 | 检查再热与风量控制的顺序与互锁条件 |
| 房间空气发闷 | 最小风量设置过低，新风不足 | 核对最小风量设定与新风量要求 |
| 风量读数异常偏低 | 风量传感器安装位置不当，管道紊流 | 检查传感器前后的直管段长度与安装位置 |

## 6. 小结

- VAV 通过调节风量满足各房间的需求，比定风量系统节能显著。
- 最小风量由新风要求和气流组织共同决定，不能简单地设为零。
- 再热会消耗额外能量，应尽量避免同时制冷和再热。
- 风量控制与再热控制之间，需要有清晰的分级和互锁逻辑。
