# 空气处理机组（AHU）

> **一句话概括：** 空气处理机组（AHU）把室外新风和室内回风混合后，经过过滤、加热或冷却、加湿或除湿，再由风机送入风管。它是把"冷热量"变成"舒适空气"的关键设备。

## 学习目标

- 说出 AHU 的主要功能段，以及每段的作用
- 理解混风比、新风比与节能之间的关系
- 理解盘管换热的基本过程，以及冷水阀如何影响送风温度
- 能说出 AHU 的典型监控点，并解释它们之间的关联

## 1. 核心概念

**AHU（Air Handling Unit）：** 集中处理空气的设备，通常包括风机、过滤段、换热段和加湿段。

**新风：** 从室外引入的空气，用于补充氧气、稀释污染物。

**回风：** 从房间回到机组的空气。

**混风：** 新风与回风按一定比例混合后再处理。

**盘管：** 内部流过冷水或热水的换热器，空气流经时被冷却或加热。

**送风温度：** 经过机组处理后送入风管的空气温度，是最常见的控制目标之一。

## 2. 为什么这样设计

房间需要的是"舒适的空气"，而不是"冷的空气"。舒适需要同时满足温度、湿度、新鲜度和洁净度。

如果每个房间单独配置一套处理设备，成本高、维护难。集中处理可以让一台机组服务多个区域，统一过滤、统一能量调节，还便于统一管理。

同时，AHU 必须能够利用室外空气的自然冷量。在春秋季节，室外空气可能比回风更凉爽，直接引入就能节省冷量，这就是**经济器（Economizer）**的基本思路。

💡 **类比：** AHU 像一个餐厅的后厨。食材（新风和回风）先经过清洗（过滤），再根据菜品要求加热或冷却（换热），最后装盘出菜（送风）。厨房的配比决定了菜的口味，就像混风比决定了送风的状态。

## 3. 系统组成与原理

### 3.1 典型的功能段

按空气流动的顺序，典型的 AHU 包括：

| 功能段 | 作用 | 常见监控点 |
| --- | --- | --- |
| 混风段 | 按比例混合新风与回风 | 混风温度、风阀开度 |
| 过滤段 | 去除粉尘与颗粒物 | 过滤器压差 |
| 冷却段（盘管） | 通过冷水降温，同时可能去湿 | 冷水阀开度、出风温度 |
| 加热段（盘管或电加热） | 通过热水或电加热升温 | 热水阀开度、出风温度 |
| 加湿段 | 向空气中补充水分 | 加湿阀开度、送风湿度 |
| 风机段 | 提供送风动力 | 风机状态、风机频率、静压 |

### 3.2 混风与经济器

混风比是新风与总风量之比。混风比的调节直接影响能耗：

- 室外空气温度低于回风，且焓值更低时，增加新风比例，可以减少冷却负荷。
- 室外空气状态较差时，减少新风比例，既节能又避免引入污染。

> [!IMPORTANT]
> 新风比例不能无限降低。为保证室内空气质量，必须满足最小新风量的要求。经济器的控制必须同时满足节能与最小新风两个目标，两者不能互相取代。

### 3.3 盘管换热

空气流过冷水盘管时，盘管表面的温度低于空气温度，空气被冷却。如果盘管表面温度低于空气的露点，部分水蒸气会凝结成水，空气同时被除湿。

因此，冷却盘管同时产生两种效果：**降低显热**（温度下降）和**降低潜热**（湿度下降）。这也是为什么 AHU 的冷却过程与空气的露点密切相关。

### 3.4 送风温度与回风温度

- **回风温度控制**：以房间回风温度为目标，调节冷水阀。
- **送风温度控制**：以送风温度为目标，调节冷水阀。送风温度控制更直接，响应更快，但需要配合房间的温度反馈来决定设定值。

## 4. 控制逻辑

以冷却段为例，典型的控制逻辑如下：

1. 控制器读取送风温度传感器的数值（AI）。
2. 与送风温度设定值比较，计算偏差。
3. 通过 PID 计算冷水阀的开度指令（AO）。
4. 阀门开度变化，改变盘管的冷量输出。
5. 送风温度趋近设定值，控制器持续修正。

**风机联锁：** 风机未运行时，冷水阀应保持关闭，防止冷量进入未流动的空气。风机停止时，风阀应关闭，以防止冷空气倒流。这类联锁由控制程序保证，不能依靠人工记忆。

**防冻保护：** 冬季水侧温度过低时，会导致盘管结冰损坏。因此需要防冻温度传感器（防冻开关）。一旦检测到低温，程序应开启热水阀、关闭新风阀并停止风机，同时发出报警。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 送风温度长期偏高 | 冷水阀未开足、冷水温度高、盘管结垢 | 检查阀门反馈、冷水供回水温度，再检查盘管清洁度 |
| 过滤器压差报警 | 滤网堵塞 | 检查压差读数，确认是否需要更换滤网 |
| 风机启动后无风或风量小 | 风阀未开、皮带松动、静压设定不当 | 检查风阀状态，确认风机频率与静压设定 |
| 冬季防冻报警频繁 | 热水温度不足、新风阀未关严、防冻传感器位置不当 | 检查热水温度与阀门，确认防冻传感器位于正确位置 |
| 冬夏交替时温度波动大 | 混风比控制不当，冷热切换频繁 | 检查混风比逻辑与温度传感器的安装位置 |

## 6. 小结

- AHU 是集中处理空气的设备，核心功能包括混风、过滤、换热、加湿和送风。
- 经济器利用室外空气的自然冷量，但必须同时满足最小新风要求。
- 冷却盘管同时影响显热和潜热，与空气露点密切相关。
- 风机与阀门的联锁、防冻保护，是保证设备安全的基本逻辑。
