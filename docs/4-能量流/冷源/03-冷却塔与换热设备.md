# 冷却塔、换热器与蓄冷罐

> **一句话概括：** 冷却塔负责把冷却水的热量排到大气中，换热器负责在两个回路之间传递热量而不混合流体，蓄冷罐则把冷量"存"起来，在需要时再释放。三者都是冷站中的重要辅助设备。

## 学习目标

- 说出冷却塔的基本散热原理，并区分开式与闭式冷却塔
- 理解板式换热器的"逼近温度"概念，以及它对换热效果的影响
- 理解蓄冷罐的分层原理，以及它在削峰填谷中的作用
- 能列出冷却塔和换热设备的常见监控点，并解释它们与运行的关系

## 1. 核心概念

**冷却塔：** 通过水与空气的直接接触，使部分冷却水蒸发，从而降低水温的设备。

**开式冷却塔：** 冷却水直接暴露在空气中，与空气直接接触。

**闭式冷却塔：** 冷却水在盘管内流动，外部喷淋水在盘管表面蒸发散热，冷却水与空气不直接接触。

**换热器：** 使两种流体在不混合的前提下交换热量的设备。

**板式换热器：** 由多块金属板组成，流体在相邻板之间交替流动，换热效率高、占地小。

**逼近温度：** 换热器中两股流体在某一端的温差，常用冷侧出口温度与热侧进口温度之差来表示（具体定义以设计文件为准）。它反映换热器的换热能力，逼近温度越小，换热越充分。

**蓄冷罐：** 在负荷较低时储存冷量，在负荷较高时释放冷量的水罐。

**分层：** 蓄冷罐中，冷水在底部，热水在顶部，中间是温度过渡层。保持良好的分层，是蓄冷效果的关键。

## 2. 为什么这样设计

冷机的热量最终要排放到大气中，这个环节的效率直接影响冷机的冷凝压力，进而影响能耗。冷却塔的散热能力越强，冷却水温度越低，冷机越节能。

换热器的作用是把两个系统隔开，例如把冷站的冷冻水与末端的冷冻水隔开，或把室外的冷却水与室内的水隔开。这样做可以防止污染、保护设备，并允许两个系统使用不同的水质和压力。

蓄冷罐的作用是"削峰填谷"。在电价较低或负荷较低时储存冷量，在负荷高峰时释放，从而减少高峰时段冷机的运行容量。这对降低运行成本、减轻电网压力都有意义。

💡 **类比：** 冷却塔像一个大型的"排汗系统"，靠水蒸发带走热量；换热器像一道隔墙，两边的人可以交换温度，但不会把物品混在一起；蓄冷罐像一个保温的"水库"，平时蓄水，用水高峰时开闸放水。

## 3. 系统组成与原理

### 3.1 冷却塔的散热原理

冷却塔的散热主要依靠两个过程：

- **蒸发散热：** 一部分水蒸发成水蒸气，带走汽化潜热。
- **对流散热：** 空气与水之间的温差使热量传递。

冷却塔的出水温度通常接近当地的湿球温度，但不可能低于湿球温度。这是因为冷却塔的冷却能力受湿球温度的限制。这一点与前面[热力学与流体基础](../../1-基础理论/03-热力学与流体基础.md)中的湿球温度概念直接相关。

> [!NOTE]
> "出水温度接近湿球温度"是理论上的理想状态，实际冷却塔的出水温度会高于湿球温度，两者之差称为"逼近度"。逼近度的具体数值由设计和厂家决定。

### 3.2 冷却塔的常见监控点

| 监控点 | 作用 |
| --- | --- |
| 冷却水进出口温度 | 反映散热能力，是风机控制的依据 |
| 风机运行状态与频率 | 用于调节散热量 |
| 集水盘液位 | 判断补水是否充足，防止水泵抽空 |
| 补水阀状态 | 补充蒸发、排污和飞溅损失的水 |
| 排污阀状态 | 控制浓缩倍数，减少水质问题 |

### 3.3 板式换热器的逼近温度

板式换热器的换热效果可以用逼近温度衡量。在冷侧和热侧之间，换热越充分，两侧的出口温度就越接近。逼近温度越小，换热器的面积和效率就越高，但投资也越大。

**例：** 一台板式换热器，热侧（回水）进口为 12 ℃，冷侧出口为 9 ℃，则按上述定义，逼近温度为 3 ℃。该数值只用于说明计算方法，实际数值取决于设计。

> [!IMPORTANT]
> 逼近温度的定义在不同资料中可能有差异。选型和调试时，应以设计文件和厂家说明为准。

### 3.4 蓄冷罐的分层

蓄冷罐的关键是保持**温度分层**：冷水在底部，热水在顶部，中间的过渡层越薄，蓄冷效率越高。

分层被破坏的常见原因包括：

- 进出水流速过大，引起紊流，导致冷热水混合。
- 进水口或出水口的布置不当，形成短路流。
- 罐体保温不良，热量从外部进入。

## 4. 控制逻辑

### 4.1 冷却塔风机控制

冷却塔风机通常以冷却水温度为控制目标：

1. 冷却水温度高于设定值，增加风机频率或增加运行风机数量。
2. 冷却水温度低于设定值，减少风机频率或减少运行风机数量。
3. 冷却水温度有下限，超过下限时应停止风机或降低频率，防止冷凝压力过低。

### 4.2 集水盘液位与补水

集水盘液位低于下限时，补水阀开启补水；液位高于上限时，补水阀关闭。若补水阀长时间开启，应检查是否存在泄漏或排污量过大。

### 4.3 蓄冷罐的释冷控制

蓄冷罐的释冷一般按负荷需要或时段策略进行：

- 负荷高峰时，开启蓄冷罐释冷，减少冷机运行容量。
- 负荷低谷时，冷机运行并向蓄冷罐蓄冷。
- 蓄冷罐的温度分层应被监测，分层变差时应发出报警。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 冷却水温度长期偏高 | 风机故障、填料结垢、风量不足、补水不足 | 检查风机运行与频率，检查填料与补水，检查进风条件 |
| 集水盘液位频繁低 | 补水阀故障、泄漏、排污过量 | 检查补水阀，检查管路和盘体泄漏，检查排污量 |
| 冷却塔飘水或水雾过大 | 挡水板损坏、风量过大、水量过大 | 检查挡水板，检查风机频率与水量分配 |
| 板式换热器换热效果下降 | 板片结垢、堵塞、流量不足 | 检查两侧压差与流量，检查板片清洗情况 |
| 蓄冷罐分层变差 | 进出水流速过大、布水不均、保温不良 | 检查进出水流速与布水装置，检查罐体保温 |

## 6. 小结

- 冷却塔通过蒸发与对流散热，出水温度受湿球温度限制。
- 板式换热器通过逼近温度衡量换热效果，换热效果与投资相互权衡。
- 蓄冷罐的关键是温度分层，分层被破坏会直接降低蓄冷效率。
- 冷却塔的风机控制需要同时考虑节能与防止冷凝压力过低。
