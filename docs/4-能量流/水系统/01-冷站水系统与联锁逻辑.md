# 数据中心水冷系统与 BA 控制逻辑

> **一句话概括：** 水冷系统把机房的热量通过冷冻水带到冷水机组，再经冷却水排到室外。BA 控制的核心，是在保证连续供冷和冗余可靠的同时，让冷站以最低能耗运行。

> **篇幅：** 约 2457 字 ｜ **预计阅读：** 约 7 分钟 ｜ **预计学习（含自测）：** 约 70 分钟

## 学习目标

- 说清冷冻水侧、冷却水侧、室外侧三个回路的关系
- 理解冷站"先开水路、后开主机"的原因
- 能描述压差旁通、台数控制、冷却水温度控制的基本逻辑

## 1. 核心概念

**冷冻水（CHW）：** 在冷水机组蒸发器与末端（精密空调、AHU）之间循环的水，供水温度通常较低。常见设计供水温度约为 12–15 ℃，以项目设计为准。

**冷却水（CW）：** 在冷水机组冷凝器与冷却塔之间循环的水，用于带走冷凝热。常见设计温度为进水 37 ℃、出水 32 ℃，以项目设计为准。

**冷却塔：** 利用水与空气的蒸发与对流换热，把冷却水的热量排到大气中。

**一次泵与二次泵：** 一次泵保证冷机侧的恒定流量，二次泵根据末端需求变化供水。是否采用一次泵与二次泵，取决于系统规模与设计。

**压差旁通阀：** 安装在供、回水总管之间，用于在末端负荷减小时维持最小流量，避免冷机因流量过低而保护停机。

**数据中心对冷站的特殊要求：**

- 连续运行，不能因一次短暂停机造成 IT 设备过温
- 通常采用 N+1 或更高冗余，保证单台设备故障时仍能供冷
- 负荷波动可能较快，控制需要有足够的响应能力

> [!TIP]
> 💡 **类比：** 烧水壶必须先加水再通电。如果没水就通电，加热元件会因过热损坏。冷水机组也是同样的道理：先让冷冻水和冷却水流动起来，再启动主机，否则蒸发器和冷凝器会在无水流的状态下运行而受损。

## 2. 为什么这样设计

### 2.1 为什么需要三个回路

- **冷冻水回路**：把热量从机房带出，需要与末端直接接触，因此水质与压力要求较高。
- **冷却水回路**：与室外接触，容易结垢、滋生微生物，与冷冻水隔离可以降低污染风险，也便于单独维护。
- **室外侧（冷却塔）**：把热量最终释放到大气，是整个系统的"散热终点"。

三个回路通过冷冻水与冷却水在冷机内的热交换相连。这种隔离设计，让每个回路可以独立调节。

### 2.2 为什么要先开水路、后开主机

冷水机组的蒸发器依赖水流换热。若水泵未运行、流量为零，蒸发器内制冷剂会因无法吸热而降温，可能导致冻结损坏。冷凝器无水流时，压力会迅速升高。

因此标准的开机顺序是：**先启动冷却塔与冷却水泵，再启动冷冻水泵，确认水流建立后，最后启动冷水机组**。停机则相反。

这一顺序必须由控制逻辑保证，而不是依靠操作人员记忆。

### 2.3 为什么要有压差旁通

末端阀门关闭较多时，系统流量减小，供回水总管压差会升高。若不设旁通，流量过低可能使冷机触发保护。压差旁通阀在压差超过设定值时开启，让部分水直接从供水回到回水，维持最小流量。

这是一种以"少量能耗"换取"系统安全"的设计。

## 3. 系统组成与原理

```
  末端（精密空调 / AHU）
        │ 冷冻水 回水 (较高温度)
        ▼
  ┌──────────────┐        ┌──────────────┐
  │ 冷冻水泵      │───────▶│ 冷水机组 蒸发器 │ 冷冻水 供水 (较低温度) ──▶ 末端
  └──────────────┘        └──────────────┘
                                 │ 制冷剂循环
                          ┌──────────────┐
                          │ 冷水机组 冷凝器 │◀─── 冷却水泵
                          └──────────────┘
                                 │ 冷却水 回水 (较高温度)
                                 ▼
                          ┌──────────────┐
                          │   冷却塔      │ ── 热量排入大气
                          └──────────────┘
                                 │ 冷却水 供水 (较低温度)
                                 ▼
                          回到冷凝器
```

**压差旁通** 位于供、回水总管之间，与末端并联，承担多余流量。

## 4. 控制逻辑

以下为典型的控制思路，具体策略以项目设计说明为准。

### 4.1 开机顺序（联锁）

1. 冷却塔进水阀开启，确认到位。
2. 冷却水泵启动，流量或压差开关确认水流建立。
3. 冷却塔风机按冷却水温度投入。
4. 冷冻水侧电动阀开启，冷冻水泵启动，确认水流。
5. 冷水机组在水流确认后启动。

任一步骤未满足条件，后续步骤不得执行，并输出对应报警。

### 4.2 台数控制（群控）

冷站群控的目标是：**在满足负荷的前提下，尽量减少同时运行的设备数量**。

常见判断依据包括：

- 冷冻水供回水温差与流量计算出的冷量
- 当前运行机组的负荷率
- 末端需求反馈（如精密空调阀位是否接近全开）

逻辑示例：

- 当系统负荷率持续高于开机阈值，并维持一段延时后，启动下一台冷机。
- 当负荷率持续低于关机阈值，并维持一段延时后，停止一台冷机。

延时的作用是防止负荷在阈值附近波动时，设备频繁启停。这种现象称为**抖动**，会缩短设备寿命。

### 4.3 冷冻水泵变频

二次泵常采用变频控制，以供回水总管压差作为控制变量：

- 压差低于设定值 → 说明末端需求增大或阀门开度增大，提高水泵转速
- 压差高于设定值 → 说明需求减小，降低水泵转速

压差设定值可以根据末端最不利环路的需求进行调整，这一做法称为**压差再设定**。

### 4.4 冷却水温度控制

冷却塔风机的运行，通常以冷却水供水温度作为控制目标：

- 冷却水温度高于设定值 → 提高风机转速或增加运行风机数量
- 冷却水温度低于设定值 → 降低风机转速或减少运行风机数量

> [!WARNING]
> 冷却水温度不宜过低。冷机厂家通常规定冷却水的最低进水温度，低于该值时冷凝压力过低，膨胀阀工作可能不稳定，甚至造成制冷剂供应不足。控制逻辑中应设置下限保护，并以厂家规定为准。

### 4.5 故障联锁与切换

- 冷机报警或水流丢失时，应自动切换到备用设备，并输出报警。
- 备用设备投入前，应检查其水路阀门状态，避免双机同时在不完整水路上运行。
- 设备故障后，锁定逻辑通常需要人工复位，防止故障设备在问题未解决时被反复启动。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 冷机因低流量报警 | 水泵故障、阀门未开到位、压差旁通失效 | 查水泵状态与运行频率，检查阀门反馈，确认旁通阀动作 |
| 冷机高压报警 | 冷却水温度高、冷却塔风机或水泵故障、冷凝器结垢 | 查冷却水进出水温度，检查冷却塔风机与水泵状态 |
| 冷站频繁启停 | 台数控制延时设置过短、负荷数据不稳定 | 查负荷曲线，核对延时参数，检查温度与流量传感器 |
| 末端温度偏高，但冷站显示正常 | 冷冻水流量不足、末端阀门未开、供水温度偏高 | 对比供回水温度与流量，检查末端阀门开度 |
| 冷却水温度持续偏高 | 冷却塔补水不足、填料结垢、风量不足 | 检查补水与液位，检查风机运行，清洗填料 |

## 6. 小结

- 水冷系统由冷冻水、冷却水、室外散热三个回路组成，各自独立又相互依赖。
- 开机必须先建立水流，再启动冷机，这一顺序由控制逻辑保证。
- 压差旁通保证最小流量，是以少量能耗换取系统安全的设计。
- 台数控制与变频控制的目标，都是在可靠供冷的前提下降低能耗。
- 冷却水温度需要上下限保护，过高影响能效，过低影响冷机稳定。
