# 水处理与水质管理

> **一句话概括：** 水系统中的水质问题不会立即爆发，却会慢慢带来结垢、腐蚀和微生物繁殖，最终降低换热效率、缩短设备寿命。水处理的目标是把这些问题控制在可接受的范围内。

## 学习目标

- 说出水系统中三类主要水质问题：结垢、腐蚀和微生物
- 理解浓缩倍数的含义，以及它与排污量的关系
- 理解旁流过滤、加药和排污的基本作用
- 能列出水质监控的常见指标，并说出它们的意义

## 1. 核心概念

**结垢：** 水中的钙、镁等离子在受热或浓缩时析出，附着在换热表面形成水垢。

**腐蚀：** 水中的溶解氧、氯离子等物质与金属发生化学反应，使金属表面逐渐损坏。

**微生物：** 水中的细菌、藻类等在适宜条件下大量繁殖，会形成生物膜，影响换热，并可能带来健康风险。

**浓缩倍数：** 循环水中某种离子的浓度与补水中该离子浓度之比。浓缩倍数越高，水越容易结垢。

**排污：** 从循环系统中排出一部分浓缩的水，以控制浓缩倍数。

**旁流过滤：** 从主循环中抽取一小部分水，经过过滤器去除悬浮物，再回到系统。

**加药：** 向循环水中添加阻垢剂、缓蚀剂、杀菌剂等化学药剂。

## 2. 为什么这样设计

冷却水在冷却塔中会因蒸发而浓缩。水分蒸发后，盐分留在水中，如果不排出，浓度会越来越高，结垢和腐蚀的风险也随之增加。

但排污也意味着浪费水和药剂。因此，水处理的核心是在**控制水质**和**节约用水**之间找到平衡。

💡 **类比：** 冷却水像一锅不断加水、又不断蒸发的汤。水蒸发后，盐会越来越浓，最后结成锅底的硬壳。排污相当于定期舀出一部分浓汤，再加入清水，让盐的浓度保持在可控范围内。

## 3. 系统组成与原理

### 3.1 三类主要问题

| 问题 | 形成条件 | 直接后果 | 常见控制手段 |
| --- | --- | --- | --- |
| 结垢 | 钙、镁离子浓度高，水温高，pH 不当 | 换热效率下降，流动阻力增加 | 阻垢剂、排污、降低浓缩倍数 |
| 腐蚀 | 溶解氧高，氯离子含量高，水质 pH 偏低 | 管道、换热器泄漏，设备寿命缩短 | 缓蚀剂、控制溶解氧、保持合适 pH |
| 微生物 | 水温适宜，有营养物质，有光照或停滞 | 生物膜形成，换热下降，存在健康风险 | 杀菌剂、旁流过滤、定期清洗 |

### 3.2 浓缩倍数与排污

浓缩倍数可以用下面的思路估算：

```
浓缩倍数 = 循环水中某离子浓度 ÷ 补水中该离子浓度
```

浓缩倍数升高，说明排污量相对减少，水中的盐分更容易析出。浓缩倍数过低，则排污和补水过多，浪费水资源。

**例：** 补水中某离子浓度为 100 mg/L，循环水中为 400 mg/L，则浓缩倍数为 4。

> [!NOTE]
> 合适的浓缩倍数取决于补水水质、药剂体系和设备材料。常见的控制范围应以水处理方案和厂家建议为准，不宜照搬其他项目的数值。

### 3.3 旁流过滤

冷却水中的悬浮物会沉积在集水盘、管道和换热表面，形成淤泥，并为微生物提供营养。旁流过滤从主循环中抽取一部分水，经过过滤后回到系统，可以持续降低悬浮物的含量。

### 3.4 加药与监测

加药通常由加药装置自动完成，控制逻辑根据水质指标调整加药量。常见监测指标包括：

| 指标 | 意义 |
| --- | --- |
| 电导率 | 反映水中溶解盐的总量，是控制浓缩倍数的常用依据 |
| pH | 影响结垢与腐蚀的倾向 |
| 余药浓度 | 反映药剂是否充足 |
| 浊度 | 反映悬浮物含量 |
| 微生物指标 | 反映杀菌效果，是健康风险的重要依据 |

> [!WARNING]
> 冷却塔的水雾可能携带微生物。在冷却塔运行和维护中，应遵守相关的卫生和安全要求，包括定期的水质检测和清洗消毒，并参照所在地区的规范执行。

## 4. 控制逻辑

### 4.1 基于电导率的排污控制

1. 电导率传感器测量循环水的电导率。
2. 控制器将电导率与设定上限比较。
3. 电导率超过上限时，开启排污阀，同时补水阀开启补充新水。
4. 电导率回落到设定值以下时，关闭排污阀。

这种方式能够自动维持浓缩倍数，但前提是传感器定期校准，并且补水的水质相对稳定。

### 4.2 加药控制

加药可以按流量或按水质指标进行控制：

- **按流量加药：** 根据补水量或循环水量，按比例加入药剂，适合水质变化较小的场合。
- **按指标加药：** 根据余药浓度或其他水质指标，调整加药量，适合水质变化较大的场合。

### 4.3 旁流过滤的运行

旁流过滤器通常按时间或压差控制。过滤器压差升高到设定值时，应进行反洗或更换滤芯。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 换热器结垢，换热效率下降 | 浓缩倍数过高，阻垢剂不足，排污不足 | 检查电导率与浓缩倍数，检查加药量与排污阀 |
| 管道或换热器出现腐蚀 | 溶解氧高，pH 偏低，缓蚀剂不足 | 检查 pH 与缓蚀剂余量，检查系统是否有空气进入 |
| 水质发黏、有异味 | 微生物繁殖，杀菌剂不足 | 检查杀菌剂余量，检查旁流过滤和清洗情况 |
| 电导率传感器读数不稳定 | 传感器结垢或未校准 | 清洗传感器，用标准溶液校准 |
| 排污量异常增大 | 排污阀泄漏，或补水电导率升高 | 检查阀门密封，检查补水水质 |

## 6. 小结

- 水处理的三类主要问题是结垢、腐蚀和微生物，它们常常相互影响。
- 浓缩倍数是水质控制的核心参数，排污与浓缩倍数直接相关。
- 旁流过滤和加药是常见的辅助手段，需要持续监测和调整。
- 水质管理涉及设备寿命、能效和健康安全，不能只看换热效果。
