# 压差控制与水力平衡

> **一句话概括：** 水系统中，每个末端都需要得到足够的流量，但不能过多。压差控制通过调节水泵，让管网中各处的压力保持合适；水力平衡则保证每个末端分到的流量与设计一致。两者配合，才能让系统既可靠又节能。

## 1. 核心概念

**压差：** 管网中两点之间的压力差。在楼控系统中，常用供回水总管的压差来反映末端的用水需求。

**压差控制：** 通过调节水泵转速或运行台数，使某个压差保持在设定值。

**压差再设定（压差复位）：** 根据末端实际需求，动态调整压差设定值。需求小时降低设定值，需求大时提高设定值。

**水力失调：** 系统中各末端的实际流量与设计流量不一致。常见表现为近处的末端流量过大，远处的末端流量不足。

**静态平衡：** 在设计流量下，通过调节阀或平衡阀设定各支路的阻力，使流量分配符合设计。

**动态平衡：** 在系统变流量运行时，通过自动平衡装置，使各末端的流量保持稳定，不受其他末端变化的影响。

## 2. 为什么这样设计

在水系统中，水总是沿阻力最小的路径流动。如果不加以调节，靠近水泵的末端会得到过多的水，远端末端则得不到足够的水。这种现象称为水力失调。

水力失调会带来两类问题：一是远端末端"够不着"，房间温度无法达标；二是近端末端"水太多"，阀门关不住，造成能耗浪费。

压差控制的意义在于：**为整个管网提供一个稳定的压力基础**。如果压差设定值过高，水泵就需要以更高的转速运行，能耗增加；如果设定值过低，远端末端就会缺水。因此，压差的设定值必须在"够用"与"节能"之间取得平衡。

💡 **类比：** 水系统像一个大型的供水网络，压差控制像控制总水压，水力平衡则像为每一条支管安装"分流阀"，确保每户居民的水量都差不多。如果只调节总水压，而不平衡各支管，离水源近的人家水会很大，远处的人家则可能没水。

## 3. 系统组成与原理

### 3.1 压差传感器的位置

压差传感器的安装位置直接影响控制的效果：

- **安装在最不利末端附近：** 能反映最远端末端的真实需求，是理想的位置。最不利末端，是指阻力最大、离水泵最远的末端。
- **安装在供回水总管之间：** 安装方便，但只能反映总的负荷，无法保证最远端末端的水压。

实际工程中，常在最不利末端附近设置压差传感器，或根据各末端阀门的反馈信号，选择需求最大的一处作为控制依据。

### 3.2 压差再设定的思路

压差再设定的基本思路是：

- 若所有末端阀门开度都较小，说明末端需求小，可以降低压差设定值。
- 若某个末端阀门接近全开，说明该末端需求大，应适当提高压差设定值。

这种思路与[设定值复位](../../5-控制策略/02-设定值复位.md)的原理相同，只是对象从送风温度或静压变成了水系统的压差。

### 3.3 水力失调的表现与平衡

| 失调类型 | 表现 | 常见原因 |
| --- | --- | --- |
| 近端过流 | 靠近水泵的末端流量过大，阀门难以调节 | 管网阻力分布不均，未做平衡 |
| 远端欠流 | 远离水泵的末端流量不足，房间温度达不到 | 未做平衡，或末端阀门选型偏小 |
| 系统性失调 | 整个系统流量不足，各末端都偏低 | 水泵选型偏小，或过滤器堵塞 |

**静态平衡**通常在调试阶段进行，通过平衡阀设定各支路阻力，使设计流量得以分配。调试完成后，平衡阀的开度应被记录和固定。

**动态平衡**用于变流量系统，通过自动平衡阀或压差无关阀，使各末端在系统压差变化时仍能保持稳定流量。

> [!IMPORTANT]
> 静态平衡只能保证在设计压差下流量正确。若系统运行压差大幅变化，而未采用动态平衡，末端流量仍会偏离设计值。

## 4. 控制逻辑

### 4.1 压差控制的基本流程

1. 压差传感器测得压差值。
2. 控制器与压差设定值比较，计算偏差。
3. 通过 PID 运算输出水泵频率指令。
4. 水泵转速变化，管网压差随之变化。
5. 控制器持续修正，使压差稳定在设定值附近。

### 4.2 压差再设定的逻辑

1. 每隔固定时间（如数分钟），检查各末端阀门的开度。
2. 若所有阀门开度都低于下限阈值，将压差设定值降低一个小步长。
3. 若任一阀门开度超过上限阈值，将压差设定值提高一个较大步长。
4. 压差设定值限制在允许的最小与最大值之间。

> [!WARNING]
> 压差设定值降得过低，远端末端可能缺水，房间温度无法达标。调整范围和步长应在调试中验证，并记录末端的运行状态。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 压差波动大，水泵频繁变速 | 控制参数不当，压差传感器安装位置不合适 | 检查 PID 参数，检查压差传感器的取压位置 |
| 远端房间温度无法达标 | 压差设定值偏低，远端末端阀门选型偏小，或未做平衡 | 检查最不利末端的阀门开度与流量，核对平衡记录 |
| 近端阀门关不住，温度难以稳定 | 近端过流，未做平衡 | 检查近端末端的流量与阀门特性，进行平衡调整 |
| 水泵能耗偏高，但末端仍不满意 | 压差设定值偏高，或存在大量节流 | 检查压差设定，检查末端阀门开度是否长期接近全开 |
| 动态平衡阀效果不明显 | 阀门选型或压差范围不匹配 | 检查阀门的工作压差范围，与实际运行压差对比 |

## 6. 小结

- 压差控制为管网提供稳定的压力基础，压差设定值需在"够用"与"节能"之间权衡。
- 压差传感器应尽量靠近最不利末端，以反映真实需求。
- 水力失调会造成远端不足、近端过剩，需要通过平衡来纠正。
- 静态平衡只保证设计压差下的流量，动态平衡能应对变流量运行。
