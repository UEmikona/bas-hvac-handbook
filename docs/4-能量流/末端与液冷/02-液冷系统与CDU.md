# 液冷系统与 CDU

> **一句话概括：** 随着机柜功率密度升高，空气的散热能力逐渐不足，液冷开始成为高密度计算设备的重要散热方式。冷却液分配单元（CDU）是液冷系统的核心，它把服务器侧的冷却液与机房的冷冻水或其他热源隔开，并精确控制它的温度、压力和流量。

## 1. 核心概念

**液冷：** 用液体代替或辅助空气，带走设备产生的热量。

**冷板式液冷：** 在发热芯片（如 CPU、GPU）上安装带有内部流道的金属冷板，冷却液流过冷板，带走芯片的热量。冷却液一般不直接接触电子元件。

**浸没式液冷：** 把服务器主板或整机直接浸入绝缘的冷却液中，热量通过液体与元件直接接触被带走。

**单相浸没式：** 冷却液始终保持液态，通过泵驱动循环散热。

**两相浸没式：** 冷却液吸热后沸腾汽化，利用相变潜热带走更多热量，蒸汽在冷凝器中重新液化。

**冷却液分配单元（CDU）：** 液冷系统中负责输送、换热和控制冷却液的核心设备。

**一次侧：** 机房的冷冻水或其他热源侧回路，与 CDU 的换热器连接。

**二次侧：** 服务器侧的冷却液回路，直接连接机柜或冷板，与一次侧通过换热器隔开。

**露点：** 空气中水蒸气开始凝结的温度。二次侧温度低于机房露点时，设备表面可能结露。

## 2. 为什么这样设计

空气的比热容和导热能力远低于水。当机柜功率达到较高密度时，要靠风扇大量送风才能带走热量，噪声、能耗和风道设计都会变得困难。液体的换热能力强，能够在较小的体积和流量下带走大量热量，因此液冷在高密度场景中具有优势。

CDU 的存在，则是为了解决液冷与机房系统之间的接口问题。服务器侧的冷却液需要控制在合适的温度、压力和洁净度下运行，而机房的冷冻水水质和压力条件往往不同。如果直接连接，两者会相互影响。CDU 通过换热器把两侧隔开，并在二次侧建立独立的控制回路。

💡 **类比：** CDU 像一个中间换热站。它一侧接着机房的大管网，另一侧接着服务器的小循环。两侧之间通过换热器传递热量，但水不混合，这样服务器侧的水质和压力可以单独管理。

## 3. 系统组成与原理

### 3.1 冷板式与浸没式的比较

| 类型 | 冷却液与电子元件的关系 | 主要优点 | 主要挑战 |
| --- | --- | --- | --- |
| 冷板式 | 冷却液在封闭的冷板内流动，不直接接触元件 | 改造相对容易，与现有服务器兼容性较好 | 需要管路接入每个发热部件，密封要求高 |
| 浸没式（单相） | 元件直接浸在绝缘液中 | 散热均匀，风扇需求减少 | 需要专用机箱，维护流程与传统不同 |
| 浸没式（两相） | 冷却液吸热沸腾，蒸汽冷凝回流 | 换热能力强，可处理更高热流密度 | 冷却液成本较高，需要严格的密封与冷凝系统 |

> [!NOTE]
> 冷却液的类型（水、水-乙二醇、绝缘油、氟化液等）会影响安全性、兼容性和成本。选择时必须参考设备厂家的材料兼容性说明。

### 3.2 CDU 的基本结构

CDU 通常包括以下部分：

| 部件 | 作用 |
| --- | --- |
| 换热器 | 连接一次侧与二次侧，传递热量 |
| 泵 | 驱动二次侧冷却液循环 |
| 过滤器 | 去除冷却液中的颗粒，保护冷板和管路 |
| 一次侧电动调节阀 | 控制进入换热器的一次侧流量，间接调节二次侧温度 |
| 膨胀与定压装置 | 维持二次侧压力稳定，吸收温度变化引起的体积变化 |
| 传感器与控制器 | 监测温度、压力、流量、液位和泄漏，并执行控制逻辑 |

**常见的分类方式：**

- **液-液型 CDU：** 一次侧接机房冷冻水或其他液体热源，通过换热器换热。换热能力强，适合高密度场景。
- **液-气型 CDU：** 通过自身的空气换热器把热量散到机房空气中，不需要接入冷冻水管路。安装相对简单，但换热能力有限。

### 3.3 二次侧温度与露点

CDU 的二次侧温度必须控制在机房露点以上，否则冷却液管路或设备表面可能结露。若水汽在电子设备表面凝结，会带来短路和腐蚀风险。因此，二次侧供水温度的设定，既要满足设备的散热需求，也要考虑机房的露点条件。

> [!IMPORTANT]
> 二次侧的具体温度要求应以服务器厂家的冷却液规格和 CDU 的设计文件为准。文中的"露点"只说明防凝露的原理，不代表任何固定温度。

### 3.4 过滤与泄漏

- **过滤：** 冷却液中的颗粒物会堵塞冷板微通道，降低换热效率。CDU 通常配备过滤器，过滤精度由厂家按设计确定。
- **泄漏检测：** 液冷系统对泄漏非常敏感。CDU 与管路应配备泄漏检测装置，并与报警和隔离逻辑联动。

## 4. 控制逻辑

### 4.1 二次侧温度控制

1. 二次侧供水温度传感器测量实际温度。
2. 控制器与设定值比较，计算偏差。
3. 通过 PID 运算调节一次侧电动调节阀的开度，改变进入换热器的一次侧流量。
4. 二次侧温度随之变化，控制器持续修正。

### 4.2 压力与流量控制

二次侧泵通常以压力或流量为控制目标，通过变频调节转速。压力过低，说明循环不足或存在泄漏；压力过高，可能导致管路或接头承压过大。

### 4.3 泄漏与保护

1. 泄漏检测装置发出信号。
2. 控制器判断泄漏位置，并发出报警。
3. 根据设计，可能需要关闭相关阀门、停止相关泵，并通知运维人员。
4. 处理完成后，需要经过检查和确认，才能重新启动。

> [!WARNING]
> 液冷系统发生泄漏时，可能同时存在电气安全风险。应按照设备厂家和现场的安全规程执行，不能在未断电或未确认安全的情况下处理设备。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 二次侧温度偏高 | 一次侧流量不足、换热器结垢、一次侧供水温度高 | 检查一次侧阀门、流量与温度，检查换热器压差 |
| 二次侧压力下降 | 泄漏、膨胀装置失效、排气不充分 | 检查泄漏检测，检查膨胀装置，检查管路排气 |
| 过滤器压差升高 | 冷却液中颗粒增多、过滤器堵塞 | 检查过滤器压差，按要求清洗或更换滤芯 |
| 冷却液温度异常波动 | 调节阀响应慢，控制参数不当 | 检查阀门动作与 PID 参数，检查传感器位置 |
| 设备表面出现凝露 | 二次侧温度低于机房露点 | 检查二次侧设定值与露点，检查机房湿度与隔热措施 |

## 6. 小结

- 冷板式液冷的冷却液在封闭流道中流动，浸没式则让元件直接接触冷却液，两者的维护和改造难度不同。
- CDU 通过换热器隔开一次侧与二次侧，使服务器侧的冷却液可以独立管理。
- 二次侧温度必须与露点配合，防止凝露。
- 泄漏检测和过滤是液冷系统可靠运行的基础。
