# 间接蒸发冷却

> **一句话概括：** 间接蒸发冷却利用水蒸发时吸热的特性降低空气温度，但不让水蒸气进入被处理的空气中。它在干燥气候中能以较低能耗获得冷量，是数据中心节能的重要手段之一。

## 学习目标

- 理解蒸发冷却的基本原理，并解释为什么干燥空气更有效
- 区分直接蒸发冷却与间接蒸发冷却
- 理解"二次空气"的作用，以及它与被处理空气之间的换热关系
- 能列出间接蒸发冷却系统的主要监控点，并说出它们与性能的关系

## 1. 核心概念

**蒸发冷却：** 水在蒸发时吸收汽化潜热，使周围空气或水温降低的现象。

**直接蒸发冷却：** 水直接与被处理的空气接触，空气在降温的同时增加湿度。

**间接蒸发冷却：** 先利用蒸发降低一股"二次空气"的温度，再通过换热器用二次空气冷却被处理的空气。被处理的空气不接触水，湿度基本不增加。

**二次空气：** 参与蒸发过程、但不直接送入房间的空气。

**湿球温度：** 在湿纱布包裹下，水蒸发达到平衡时测得的温度。它是蒸发冷却能达到的理论最低温度的参考。

**逼近度：** 系统出风温度与湿球温度之差，反映蒸发冷却的完善程度。逼近度越小，蒸发冷却越充分。

## 2. 为什么这样设计

数据中心需要全年排出大量热量。传统机械制冷依靠压缩机，耗电较大。在干燥地区，室外空气的湿球温度较低，如果能利用水的蒸发来降温，就能显著减少压缩机的使用时间。

但直接蒸发冷却会增加送风的湿度。对于数据中心来说，湿度增加可能带来凝露、腐蚀和设备可靠性的问题。因此，间接蒸发冷却的设计目标是：**在获得蒸发冷却效果的同时，避免把水汽直接带入机房。**

💡 **类比：** 直接蒸发冷却像直接对着一杯饮料吹风，饮料会降温，但你也会被水汽打湿。间接蒸发冷却像先在旁边的杯子外壁上洒水让它降温，再让饮料通过杯壁与它换热。饮料没有直接接触水，却同样被降温了。

## 3. 系统组成与原理

### 3.1 基本结构

间接蒸发冷却系统通常包括：

| 部件 | 作用 |
| --- | --- |
| 空气-空气换热器 | 让被处理的空气与二次空气换热，两股空气不直接混合 |
| 蒸发段（直接蒸发段） | 对二次空气进行加湿，使其温度降低 |
| 风机 | 驱动一次空气（被处理空气）和二次空气流动 |
| 水循环与补水系统 | 向蒸发段供水，并补充蒸发损失的水 |
| 传感器与控制器 | 监测温度、湿度、水位，并执行控制逻辑 |

### 3.2 工作过程

1. 室外空气（或回风）作为一次空气进入换热器的一侧。
2. 另一部分空气作为二次空气，先经过蒸发段，被喷水加湿，温度降低。
3. 降温后的二次空气进入换热器的另一侧，吸收一次空气的热量。
4. 一次空气的温度降低，被送入机房，而其湿度基本保持不变。
5. 二次空气吸收热量后排出室外。

### 3.3 湿球温度与出风温度

间接蒸发冷却的出风温度不可能低于室外空气的湿球温度，这与冷却塔的原理相似。实际出风温度与湿球温度之间的差值，即逼近度，取决于换热器效率和蒸发段的性能。

**例：** 若当地湿球温度为 20 ℃，系统逼近度为 4 ℃，则理论上的出风温度约为 24 ℃。实际数值取决于当地气候和系统设计，此处仅用于说明概念。

> [!NOTE]
> 湿球温度是气候条件的一部分，会随季节和时间变化。间接蒸发冷却的适用性在很大程度上取决于当地气候，不宜在湿热地区盲目采用。

### 3.4 水耗与水质

蒸发冷却需要消耗水。水耗包括蒸发掉的水和排污损失的水。水耗与气候、系统效率和排污策略有关。

由于蒸发段的水会在空气中蒸发，水中的盐分会浓缩，因此需要水质管理。前面[水处理与水质管理](../水系统/03-水处理与水质管理.md)中的内容，同样适用于间接蒸发冷却的水系统。

## 4. 控制逻辑

### 4.1 运行模式选择

间接蒸发冷却常根据室外条件切换运行模式：

- **间接蒸发冷却模式：** 室外湿球温度较低，蒸发冷却效果明显，优先使用。
- **机械制冷模式：** 室外湿球温度较高，蒸发冷却无法满足需求，启动压缩机补充制冷。
- **混合模式：** 在两者之间，按需求同时使用蒸发冷却与机械制冷。

### 4.2 蒸发段供水控制

1. 控制器根据室外湿球温度和送风温度，判断是否需要开启蒸发段。
2. 开启蒸发段时，水泵运行，喷水装置向填料或蒸发面供水。
3. 若水位过低，补水阀开启补水；若水质指标超出范围，应启动排污。
4. 若风机停止或送风温度已满足要求，蒸发段应停止供水。

> [!IMPORTANT]
> 蒸发段停止供水后，填料和水盘可能残留水分，长期停滞会滋生微生物。应按照厂家要求进行排水、清洗和维护。

### 4.3 防止结露与积水

若被处理空气的温度低于露点，换热器表面可能结露。控制器应监测送风温度与露点的关系，必要时调整运行模式，防止水汽进入送风。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 出风温度偏高 | 湿球温度偏高、逼近度增大、蒸发段供水不足 | 检查室外湿球温度、蒸发段供水状况与填料润湿情况 |
| 蒸发段填料结垢 | 水质管理不足，浓缩倍数过高 | 检查水质指标，检查排污与加药，清洗填料 |
| 送风湿度偏高 | 换热器泄漏，或一次空气与二次空气混合 | 检查换热器密封，检查两股空气的压差与风阀状态 |
| 水耗异常增大 | 排污量过大，补水阀泄漏 | 检查排污阀与补水阀，检查水表读数 |
| 运行模式切换频繁 | 切换阈值设置不当，室外温度波动大 | 检查切换阈值与延时设置，观察历史数据 |

## 6. 小结

- 间接蒸发冷却利用水的蒸发降温，但被处理的空气不直接接触水，湿度基本保持不变。
- 出风温度的理论下限受室外湿球温度限制，适用性高度依赖当地气候。
- 水耗和水质管理是系统运行的重要组成部分。
- 运行模式的切换和防结露控制，是保证可靠性的关键。
