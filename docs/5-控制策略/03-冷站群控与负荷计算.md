# 冷站群控与负荷计算

> **一句话概括：** 冷站群控是把冷机、冷冻水泵、冷却水泵和冷却塔作为一个整体，根据实际负荷统一决定运行台数和运行参数。它的核心目标是：在满足需求的前提下，让整个冷站的总能耗最低。

## 学习目标

- 说明冷站负荷的计算方法，并能根据供回水温差和流量估算冷量
- 理解台数控制的基本逻辑，以及启停延时的作用
- 理解群控与单机控制的区别
- 能说出冷站群控的主要监控点，并解释它们与运行决策的关系

## 1. 核心概念

**冷站：** 包括冷水机组、水泵、冷却塔、换热器、蓄冷罐等设备的集中制冷系统。

**冷站群控：** 由一套控制逻辑统一决定冷站内各设备的启停和运行参数，而不是各设备独立运行。

**冷量（负荷）：** 冷冻水带走的热量，常以 kW 或 RT 表示。在水系统中，可由流量和供回水温差计算。

**台数控制：** 根据负荷决定开启的冷机台数，并在负荷变化时增减台数。

**启停延时：** 在满足开机或关机条件后，等待一段时间再动作，防止负荷在阈值附近波动时频繁启停。

**最小运行时间：** 设备启动后，必须运行一段时间才能停止，保护设备并避免频繁启停。

**系统能效：** 冷站总耗电量与总冷量之比，常用 kW/RT 表示。系统能效越低，单位冷量的耗电越多。

## 2. 为什么这样设计

冷站由多台设备组成，它们之间存在相互影响。例如，冷机台数增加后，冷却水的需求也增加，冷却塔的风机和冷却水泵的能耗也会随之变化。如果每台设备各自控制，很可能出现"冷机节能了，但水泵和冷却塔耗能增加"的情况。

群控的意义在于：**从系统层面看待能耗，而不是只看单台设备的效率。** 这也是为什么冷站控制通常需要同时考虑冷机、水泵和冷却塔之间的协调。

💡 **类比：** 群控像一个车队的调度。单辆车可能很省油，但车队的总油耗还取决于车辆数量、行驶路线和装载情况。调度员需要统一安排，而不是让每辆车自己决定。

## 3. 系统组成与原理

### 3.1 负荷的计算

冷站负荷可以用水侧公式估算：

```
Q(kW) ≈ 1.163 × 流量(m³/h) × 供回水温差(℃)
```

这一公式与[热力学与流体基础](../1-基础理论/03-热力学与流体基础.md)中的水侧冷量计算一致。

**例：** 冷冻水流量 300 m³/h，供回水温差 5 ℃，则冷量约为 1.163 × 300 × 5 ≈ 1744 kW。

> [!IMPORTANT]
> 流量计的精度和安装位置会直接影响负荷计算结果。若流量计安装在不合适的位置，或直管段不足，计算出的负荷可能偏大或偏小。负荷计算的结果应与其他负荷指标（如冷机功率）相互校核。

### 3.2 负荷的其他估算方式

除了流量和温差，还可以用以下方式辅助判断负荷：

| 方式 | 说明 | 局限 |
| --- | --- | --- |
| 末端阀门开度 | 阀门平均开度反映末端需求 | 阀门特性不同，开度与负荷不是线性关系 |
| 冷机负荷率 | 运行冷机的功率占额定值的比例 | 依赖冷机的运行状态，需考虑部分负荷效率 |
| 历史数据与负荷预测 | 根据历史曲线预测未来负荷 | 需要足够长的数据积累，突发负荷难以预测 |

### 3.3 台数控制的基本结构

台数控制通常包括以下要素：

| 要素 | 作用 |
| --- | --- |
| 开机阈值 | 负荷超过该值时，考虑增加一台冷机 |
| 关机阈值 | 负荷低于该值时，考虑减少一台冷机 |
| 启停延时 | 满足条件后，需持续一段时间才动作 |
| 最小运行时间 | 冷机启动后，至少运行一段时间才能停止 |
| 备用与轮换 | 在多台设备之间轮换运行，平衡磨损 |

**关键要点：** 开机阈值应高于关机阈值，两者之间需要留有"死区"。若两者相同，负荷稍有波动就会反复启停。

## 4. 控制逻辑

### 4.1 开机顺序

冷站的开机顺序通常为：

1. 启动冷却塔风机和冷却水泵，确认冷却水流动。
2. 启动冷冻水泵，确认冷冻水流动。
3. 启动冷机，并确认其运行状态正常。
4. 根据负荷，逐步增加冷机的输出。

这一顺序与[冷站水系统与联锁逻辑](../4-能量流/水系统/01-冷站水系统与联锁逻辑.md)中的原则一致，即先建立水流，再启动主机。

### 4.2 增加台数的判断

1. 计算当前负荷，并与开机阈值比较。
2. 若负荷持续高于开机阈值，且运行冷机的输出已接近上限，满足延时条件后，启动下一台冷机。
3. 新冷机启动后，相关的冷却水泵和冷冻水泵也应同步启动，并确认水流。

### 4.3 减少台数的判断

1. 计算当前负荷，并与关机阈值比较。
2. 若负荷持续低于关机阈值，且运行冷机的负荷率较低，满足延时和最小运行时间条件后，停止一台冷机。
3. 停止冷机后，应按顺序停止对应的水泵和冷却塔风机，并确认没有冷量需求。

### 4.4 能效优化的思路

群控的能效优化通常考虑以下方面：

- **冷机与水泵的权衡：** 增加冷机台数可能提高冷机效率，但也会增加水泵能耗。需要根据实际数据判断最优组合。
- **冷却水温度设定：** 冷却水温度降低，冷机效率提高，但冷却塔风机的能耗增加。需要找到两者之间的平衡点。
- **冷冻水温度设定：** 冷冻水供水温度提高，冷机效率提高，但末端的除湿能力可能下降。设定值需与末端需求相匹配。

> [!WARNING]
> 能效优化的设定值必须在设备允许的范围内运行。冷机对冷却水温度有下限要求，冷冻水温度也受末端除湿和设备运行条件的限制。不能为追求能效而突破设备的安全范围。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 冷机频繁启停 | 开机与关机阈值过于接近，延时过短 | 检查阈值设定与延时参数，观察负荷曲线 |
| 负荷计算结果异常 | 流量计故障或安装位置不当，温度传感器偏差 | 校核流量与温度传感器，用冷机功率互相验证 |
| 增加台数后效果不明显 | 冷却水或冷冻水流量不足，新设备未正确投入 | 检查新冷机的水流状态与水泵运行情况 |
| 系统能效偏低 | 运行台数不合理，冷却水温度过高或过低 | 检查台数组合与设定值，对比历史能效数据 |
| 群控逻辑与实际动作不一致 | 点表错误、联锁条件缺失或程序版本不符 | 对照控制序列与点表，逐条核对逻辑 |

## 6. 小结

- 冷站群控从系统层面统筹冷机、水泵和冷却塔，目标是总能耗最低。
- 负荷可由水侧公式估算，但需要与其他指标相互校核。
- 台数控制依靠开机阈值、关机阈值和延时，阈值之间必须留有死区。
- 能效优化需要在设备安全范围内寻找平衡，不能只追求单一设备的效率。
