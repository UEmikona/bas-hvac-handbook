# 设定值复位

> **一句话概括：** 设定值复位是指根据实际负荷，动态调整控制目标值，使系统在满足需求的前提下，尽量减少能耗。它是 BA 系统中最常见、也最容易被忽视的节能手段之一。

> **篇幅：** 约 1914 字 ｜ **预计阅读：** 约 5 分钟 ｜ **预计学习（含自测）：** 约 50 分钟

## 学习目标

- 理解"固定设定值"与"复位"的区别
- 说出送风温度复位、静压复位、压差复位的基本思路
- 理解"修剪与响应"（Trim and Respond）逻辑的基本过程
- 能说明设定值复位可能带来的风险，并给出避免方法

## 1. 核心概念

**设定值：** 控制器希望达到的目标值，如送风温度、静压、压差。

**固定设定值：** 整个运行期间保持不变的设定值。

**设定值复位：** 根据实际工况，动态调整设定值。例如在负荷较低时提高送风温度，减少冷量消耗。

**修剪与响应（Trim and Respond）：** 一种常见的复位方法：先缓慢地"修剪"设定值，使其逐步向节能方向移动；当有房间反馈需求不足时，再"响应"，快速恢复设定值。

**需求信号：** 反映系统是否满足需求的信号，例如房间温度是否达标、阀门是否接近全开。

## 2. 为什么这样设计

固定的设定值通常是按最不利工况设计的。例如，为了保证最热的房间能够降温，送风温度可能被设定得很低。但在大多数时间，系统的负荷远小于最不利工况，此时过低的送风温度就是在浪费能量。

设定值复位的思路是：**让系统在满足所有房间需求的前提下，把设定值调整到尽可能节能的位置。**

这里的关键词是"满足所有房间需求"。如果复位过度，部分房间会过冷、过热或缺风，舒适性和设备安全都会受影响。

💡 **类比：** 设定值复位像汽车的巡航控制。平路时保持较低的速度省油，遇到上坡时自动提高输出以保持车速。设定值复位的目标也是这样：需求小的时候节省能量，需求大的时候自动提供足够的支持。

## 3. 系统组成与原理

### 3.1 三种常见的复位对象

| 复位对象 | 节能机理 | 常见需求信号 |
| --- | --- | --- |
| 送风温度 | 送风温度提高，冷却所需的能量减少，冷水机组效率提高 | 各房间的冷却需求，阀门开度 |
| 静压（风管静压） | 静压降低，风机功率下降 | 各 VAV 末端的风阀开度 |
| 压差（水系统压差） | 压差降低，水泵功率下降 | 各末端水阀的开度 |

### 3.2 送风温度复位的基本思路

1. 检查各房间的冷却需求，例如 VAV 风阀的开度。
2. 若所有房间的风阀开度都低于某个阈值（如 90 %），说明送风温度还有提升空间，可以逐步提高设定值。
3. 若有任一房间的风阀接近全开，或房间温度超过允许范围，说明需求增加，应降低设定值。
4. 设定值变化幅度和频率都应限制，避免频繁波动。

> [!WARNING]
> 送风温度提高后，若湿度控制不当，可能导致房间湿度偏高，甚至结露。因此送风温度复位必须与湿度控制一并考虑。

### 3.3 静压复位与修剪响应

静压复位同样遵循"需求驱动"的原则：

- 当所有 VAV 风阀开度都较小时，说明风管静压偏高，可以逐步降低静压设定值。
- 当某个风阀接近全开、房间风量不足时，说明静压偏低，应适当提高静压设定值。

**修剪与响应的典型过程：**

| 阶段 | 动作 | 目的 |
| --- | --- | --- |
| 修剪（Trim） | 每隔一段时间，小幅降低设定值 | 逐步逼近节能位置 |
| 响应（Respond） | 当有需求反馈时，按步长提高设定值 | 快速恢复，保证需求得到满足 |

修剪的速度应慢于响应的速度。这样系统既能缓慢节能，又能在需求增加时及时反应。

## 4. 控制逻辑

以静压复位为例，控制步骤如下：

1. 每隔固定时间（如 5 分钟）检查一次所有 VAV 风阀的开度。
2. 若所有风阀开度都低于下限阈值，将静压设定值降低一个小步长（修剪）。
3. 若任一风阀开度超过上限阈值，将静压设定值提高一个较大步长（响应）。
4. 设定值限制在允许的最小值与最大值之间。
5. 记录每次变化的时间和数值，便于后续分析。

**关键参数：** 检查间隔、阈值、修剪步长、响应步长、最小值与最大值。这些参数需要在调试中确定，不应照搬其他项目的数值。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 设定值长期不变化 | 需求信号异常、复位条件未满足、程序未运行 | 检查需求信号的读数，确认复位程序是否启用 |
| 设定值频繁波动 | 修剪与响应的步长不合理、阈值过于接近 | 检查阈值与步长，观察历史趋势 |
| 部分房间过热或过冷 | 复位过度，需求信号未能代表所有房间 | 检查最不利房间的温度与风阀开度，确认需求信号选择是否合理 |
| 节能效果不明显 | 设定值的上下限过于保守 | 检查复位范围，结合历史数据重新评估 |
| 复位后湿度偏高 | 送风温度提高，湿度控制未同步调整 | 检查送风湿度与除湿逻辑 |

## 6. 小结

- 固定设定值通常按最不利工况设计，大部分时间存在浪费。
- 设定值复位的前提是"满足所有房间的需求"，复位过度会损害舒适性。
- 修剪与响应是常见的复位方法：修剪缓慢，响应迅速。
- 复位参数必须通过调试确定，不能照搬其他项目。
