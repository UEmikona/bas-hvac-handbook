# 水泵、风机与变频

> **一句话概括：** 水泵和风机是输送能量的"动力源"。它们的运行点由系统阻力决定，而变频器通过改变转速来匹配需求，是楼控系统中最重要的节能手段之一。

> **篇幅：** 约 1844 字 ｜ **预计阅读：** 约 5 分钟 ｜ **预计学习（含自测）：** 约 50 分钟

## 学习目标

- 说出水泵或风机的工作点由哪两条曲线决定
- 理解相似定律在变频调速中的作用，并能做简单的功率估算
- 说明并联、串联运行的基本特点，以及为什么并联时要注意单台工况
- 能列出变频水泵或风机的常见监控点，并解释它们的意义

## 1. 核心概念

**工作点：** 设备的性能曲线（流量与压头或风压的关系）与系统阻力曲线的交点，是设备实际运行的状态。

**性能曲线：** 厂家给出的设备参数关系，包括流量、扬程或风压、功率和效率。

**系统阻力曲线：** 管网或风道阻力随流量变化的关系，流量越大，阻力越大。

**变频器（VFD）：** 通过改变电源频率来调节电机转速的装置。

**最小流量：** 水泵在运行时必须保持的最低流量，低于此值会导致发热或振动，通常由厂家规定。

## 2. 为什么这样设计

设计时的水泵和风机，通常按最不利工况选型，留有余量。但实际运行中，大部分时间负荷低于设计值。如果仍按满速运行，多出的能量会通过阀门或风阀"节流"消耗掉，造成浪费。

变频调速的思路是：**不靠节流消耗多余的能量，而是直接降低转速。** 这样做的效果在前面的相似定律中已经说明：功率大致与转速的立方成正比。

💡 **类比：** 同样是给一桶水加压，你可以用全力压水泵，再用阀门把多余的水放掉；也可以按需要的力度压。前一种做法就像"节流"，后一种做法就像"变频"。

## 3. 系统组成与原理

### 3.1 工作点

水泵或风机在系统中的实际状态，由性能曲线与阻力曲线的交点决定：

- 阻力增加（例如阀门关小），阻力曲线上移，工作点向流量小的方向移动。
- 转速降低，性能曲线下移，工作点同样向流量小的方向移动。

因此，调节流量有两种方式：**节流调节**（靠阀门改变阻力）和**变速调节**（靠转速改变性能）。两者的能耗差异很大。

### 3.2 相似定律的应用

| 参数 | 与转速的关系 | 转速为 80 % 时 |
| --- | --- | --- |
| 流量 | 正比于转速 | 约为 80 % |
| 压头或风压 | 正比于转速的平方 | 约为 64 % |
| 功率 | 正比于转速的立方 | 约为 51 % |

> [!IMPORTANT]
> 相似定律是近似关系，适用于同一台设备、效率基本不变的情况。实际功率还受电机效率、变频器效率和管网特性影响。估算结果应以厂家曲线和现场测量为准。

### 3.3 并联与串联

- **并联：** 多台水泵或风机向同一管网供水或送风。总流量增加，但每台设备的工况会因管网阻力而变化，单台运行和多台运行时的工作点不同。
- **串联：** 两台设备前后连接，压头叠加，流量基本相同。较少用于楼控系统的常规设计。

**注意：** 并联时，若只启动一台大泵，其工作点可能偏离高效区，甚至进入不稳定区，因此台数切换时需要检查工况。

### 3.4 常见的变频控制方式

| 控制方式 | 控制目标 | 常见应用 |
| --- | --- | --- |
| 压差控制 | 维持管网两点压差恒定或随需求变化 | 二次泵冷冻水系统 |
| 温度控制 | 维持某点的温度 | 冷却水泵或冷却塔风机 |
| 流量控制 | 维持某段流量 | 特定工艺管路 |
| 静压控制 | 维持风管静压 | 风机变频 |

## 4. 控制逻辑

以二次泵冷冻水系统为例：

1. 压差传感器测得供回水总管压差。
2. 与压差设定值比较，计算偏差。
3. 通过 PID 运算输出频率指令。
4. 水泵转速变化，流量随之调整。
5. 末端阀门开度变化时，系统阻力改变，压差随之变化，控制器持续修正。

**保护逻辑：** 变频器频率不低于最低限值；水泵运行时，流量或压差低于保护值应发出报警；故障时自动切换备用泵。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 水泵运行声音异常、振动大 | 工况偏离高效区、轴承磨损、气蚀 | 检查运行频率与性能曲线，检查进口压力和轴承状态 |
| 变频后节能效果不明显 | 压差设定值过高，或阀门节流过多 | 检查压差设定与末端阀门开度，检查是否存在大量节流 |
| 变频器频繁过流报警 | 启停过于频繁，加减速时间设置过短 | 检查加减速时间，检查控制逻辑的启停条件 |
| 流量低于最小值 | 末端全部关闭，旁通阀未动作 | 检查旁通阀动作与最小流量保护逻辑 |
| 风机风量不足 | 风机频率限制，或风道阻力增大 | 检查风机频率、静压设定和风阀开度 |

## 6. 小结

- 水泵和风机的运行点由性能曲线和系统阻力决定。
- 变速调节比节流调节更节能，原因在于功率随转速的立方变化。
- 并联台数切换时，要注意单台工况是否在合理范围。
- 变频控制的关键在于选择合适的控制目标，并设置好最小频率和保护逻辑。
