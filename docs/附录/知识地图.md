# 知识地图

本页列出手册计划覆盖的全部知识点，并标注依据来源与完成状态。

## 分类逻辑

知识点按两个维度归类：

1. **能量流**：冷量或热量沿"冷源 → 输配 → 末端 → 室内环境"的路径流动。
2. **信息流**：信号沿"感知 → 通信 → 控制 → 诊断"的路径流动。

同一知识点可能同时涉及两条主线，此时以"主要作用所在环节"为准归类。另设**应用场景**一列，标注该知识点主要用于数据中心、商业建筑还是通用场景。

## 本次调研新增的知识点

与最初规划相比，网上公开资料中出现了以下值得补充的知识点：

1. **ASHRAE Guideline 36（高性能控制序列）**：提供标准化的空气侧与水侧控制序列，是"控制策略"一章的核心依据。
2. **ASHRAE Guideline 13（BAS 规格与性能监测）**：说明如何在设计阶段规划监测点与诊断方式。
3. **调试与功能性能测试（FPT）**：NIST 的 HVAC-Cx 工具展示了如何用自动化测试验证控制序列。
4. **自动故障诊断（FDD）**：从"只报硬故障"转向"发现软故障"，是运维章节的重要内容。
5. **CDU 与液冷的二次侧设计**：随着高密度机柜普及，液冷已经是数据中心知识体系中不可缺少的部分。
