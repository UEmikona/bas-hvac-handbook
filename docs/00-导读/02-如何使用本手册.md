# 如何使用本手册

## 一、你适合从哪里开始

| 你的情况 | 建议路径 |
| --- | --- |
| 完全没有相关背景 | 从[建筑自动化概述](../1-基础理论/01-建筑自动化概述.md)开始，按[学习路线](../00-学习路线.md)顺序学习 |
| 有电气或机械基础，想转楼宇自控 | 先读[闭环控制与 PID](../1-基础理论/02-闭环控制与PID.md)，再读[制冷循环基础](../4-能量流/冷源/01-制冷循环基础.md) |
| 已在机房或楼控岗位工作，想系统化 | 直接查[知识地图](../附录/知识地图.md)，找到缺口后补读对应章节 |
| 准备面试或岗位交流 | 重点读每章的"为什么这样设计"和自测问题 |

## 二、每章怎么读

每一章都有固定结构，建议按顺序阅读：

1. **一句话概括**：先看本章要解决什么问题。
2. **学习目标**：确认学完能做什么。
3. **核心概念**：掌握术语。遇到不认识的词，可以查[术语表](../附录/术语表.md)。
4. **为什么这样设计**：这一节最重要。理解了原因，后面的细节就容易记住。
5. **系统组成与原理、控制逻辑**：按能量或信号的流向理解。
6. **常见故障与排查**：把前面的知识放到实际问题中检验。
7. **自测问题**：读完后能不能回答？答不上来，就回到"为什么"一节重读。

带有 💡 标记的提示框是类比，只用来帮助理解，不能当作严格定义。

## 三、章节之间怎么连起来

每章末尾的"知识联动"列出了相关章节，并写明了为什么相关。如果想看整张关系图，可以阅读[知识网络](../附录/知识网络.md)，里面按能量流、信息流和优化三条主线给出了推荐路径。

## 三、标记说明

| 标记 | 含义 |
| --- | --- |
| 💡 类比 | 用日常事物帮助理解抽象概念 |
| `[!NOTE]` | 补充说明或适用范围 |
| `[!IMPORTANT]` | 必须注意的原则，忽略会导致错误判断 |
| `[!WARNING]` | 可能导致设备损坏或安全风险 |
| 待编写 | 该知识点已规划，但内容尚未完成 |
| 需核实 | 来源不够权威，写入正文前必须回到原始资料确认 |

## 四、如何配合外部资料

本手册是学习地图，不能替代下列资料。学习时建议同步参考：

- **标准规范**：见[标准规范索引](../附录/标准规范索引.md)中的编号，以现行版本为准。
- **厂家手册**：了解具体设备的参数、接线和调试方法。
- **真实的点表和控制序列**：如果你能接触到项目资料，对照阅读效果最好。
- **工程现场**：设备的声音、温度、压力，很多是文字无法替代的经验。

## 五、如何提出问题或修改

- 发现错误：在仓库提交 Issue，注明章节和原文，并附上来源。
- 想补充内容：先看[编写规范](../附录/排版规范.md)和[贡献指南](../../CONTRIBUTING.md)，再提交 Pull Request。
- 有疑问：可以在 Issue 中提出，我们会尽量给出说明。
