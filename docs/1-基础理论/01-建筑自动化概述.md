# 建筑自动化概述

> **一句话概括：** 建筑自动化（BA，Building Automation）用传感器采集环境与设备状态，由控制器按预设逻辑计算，再通过执行器调节设备，目的是在保证舒适与可靠的前提下降低能耗、减少人工巡检。

## 学习目标

- 说清 BA 与 BMS、DCIM 的关系与区别
- 能列出智能建筑 5A 体系中的 BA 部分包含哪些子系统
- 能画出 BA 系统的三层结构，并说明每层的职责

## 1. 核心概念

**BA（楼宇自动化）** 指对建筑内的机电设备进行监测、控制与管理的自动化系统。国内常称"楼控系统"或"BAS（Building Automation System）"。

**智能建筑 5A 体系** 是国内常见的分类方式：

| 缩写 | 全称 | 中文 | 主要内容 |
| --- | --- | --- | --- |
| BA | Building Automation | 楼宇自动化 | 暖通、给排水、供配电、照明、电梯等 |
| OA | Office Automation | 办公自动化 | 办公信息处理 |
| CA | Communication Automation | 通信自动化 | 语音、数据、网络 |
| FA | Fire Automation | 消防自动化 | 火灾探测、报警与联动 |
| SA | Security Automation | 安防自动化 | 视频监控、门禁、入侵报警 |

> [!NOTE]
> 部分资料将第五项写作 MA（管理自动化）。不同机构的叫法略有差异，以你所在项目的合同和设计文件为准。

**BMS 与 DCIM 的关系：** 在数据中心场景下，BA 通常指暖通与配电等楼控部分，BMS 更偏向广义的监控平台，DCIM 则侧重 IT 资产与容量管理。三者的数据常常互通，但职责边界要以项目定义为准。

> [!TIP]
> 💡 **类比：** 可以把 BA 系统想象成人体的神经系统。传感器像感觉器官，负责感知冷热和压力；DDC 控制器像脊髓，能在本地快速做出反应；执行器像肌肉，负责动作；中央站像大脑，负责整体掌握和记录。类比只说明分工，实际系统中的"大脑"并不直接控制每个动作。

## 2. 为什么这样设计

建筑内的机电设备数量多、分布广、运行参数相互关联。如果每台设备都靠人工现场操作，会出现三类问题：

1. **响应慢：** 温度异常要等人发现，设备可能已经超限运行。
2. **能耗高：** 没有按负荷调节，设备长期在额定工况运行。
3. **难追溯：** 没有统一记录，故障发生时无法还原过程。

BA 把"感知、判断、执行、记录"放到系统中完成，人员从巡检转向监督与异常处理。这就是它存在的根本理由。

## 3. 系统组成与原理

BA 系统通常分为三层：

```
┌─────────────────────────────┐
│ 管理层   中央站 / 上位机 / 报表 │  显示、历史趋势、报警、策略下发
├─────────────────────────────┤
│ 控制层   DDC 控制器 / PLC     │  运行控制逻辑，独立完成本地控制
├─────────────────────────────┤
│ 现场层   传感器 / 执行器 / 开关 │  采集信号，驱动阀门、风机、水泵
└─────────────────────────────┘
```

**为什么控制层要独立运行？** 如果中央站或网络中断，DDC 仍能按本地程序继续控制设备。这叫**本地自治**，是保证关键设备不因通信故障而失控的基本设计。

**信号类型：** 现场层与控制层之间常见的信号包括：

| 类型 | 含义 | 示例 |
| --- | --- | --- |
| AI（模拟量输入） | 连续变化的量 | 温度、压力、湿度 |
| AO（模拟量输出） | 连续控制信号 | 0–10 V 或 4–20 mA 驱动阀门开度 |
| DI（数字量输入） | 开关状态 | 风机运行反馈、过滤网压差报警 |
| DO（数字量输出） | 启停命令 | 启动水泵、开关电磁阀 |

这四类信号简称 **AI / AO / DI / DO**，它们构成了点表（I/O 清单）的基础。

## 4. 控制逻辑

以一台空气处理机组为例，BA 的基本逻辑如下：

1. 控制器读取回风温度传感器的值（AI）。
2. 与设定值比较，计算偏差。
3. 通过 PID 运算得出阀门开度指令（AO）。
4. 执行器动作，改变冷水流量，温度随之变化。
5. 控制器持续重复上述过程，直到偏差趋近于零。

这一闭环过程在第 [闭环控制与 PID](02-闭环控制与PID.md) 中详细展开。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 中央站显示某点无数据 | 通信中断、点位地址错误、控制器离线 | 先看控制器电源与指示灯，再看网络，最后核对点表地址 |
| 阀门开度与指令不符 | 执行器接线错误、阀门卡涩、行程设置错误 | 手动给定开度，观察阀位反馈，检查行程标定 |
| 温度读数明显偏离 | 传感器损坏、安装位置不当、接线松动 | 用标准温度计对比，检查安装位置是否在气流死角 |

## 6. 小结

- BA 通过感知、判断、执行、记录四个环节替代人工巡检。
- 5A 中的 BA 管理的是建筑机电设备，它与 OA、CA、FA、SA 构成智能建筑的整体。
- 三层结构中，控制层的本地自治能力是可靠运行的关键。
- AI、AO、DI、DO 是理解点表与控制逻辑的基础语言。
