# 热力学与流体基础

> **一句话概括：** 空调和水系统做的事情，本质上是"搬运能量"。搞清楚热量怎么算、空气和水各自能带多少热，后面所有的控制逻辑才有依据。

> **篇幅：** 约 1584 字 ｜ **预计阅读：** 约 5 分钟 ｜ **预计学习（含自测）：** 约 50 分钟

## 学习目标

- 区分显热与潜热，并说出它们在空调中的意义
- 会用"Q = 流量 × 比热 × 温差"的思路估算冷量
- 理解湿空气的干球温度、湿球温度、露点和焓值之间的关系
- 说出水泵和风机的相似定律，并解释变频节能的原因

## 1. 核心概念

**热量与温度：** 温度反映物体的冷热程度，热量是能量的转移。两者不同：一杯 100 ℃ 的水温度高，但它的热量不一定比一大池 30 ℃ 的水多。

**显热：** 物质温度变化时吸收或放出的热量。空气温度从 26 ℃ 降到 22 ℃，这部分变化就是显热。

**潜热：** 物质状态改变时吸收或放出的热量，温度基本不变。水蒸气凝结成水时放出的，就是潜热。

**比热容：** 单位质量物质升高 1 ℃ 所需的热量。水的比热容约为 4.19 kJ/(kg·K)，远大于空气，这是水系统能高效输送热量的原因之一。

**冷量单位：** 工程中常用 kW 表示功率。冷吨（RT）也很常见，1 RT 约等于 3.517 kW。

## 2. 为什么这样设计

如果只看温度，无法判断一个系统能带走多少热量。同样是降温 5 ℃，一股大流量的水可能带走很多热，一股小流量的空气可能很少。

因此工程师要同时看**流量**和**温差**。这也是为什么冷站要同时测量冷冻水的供回水温度和流量，才能算出实际负荷。若只测温度，不测流量，就无法判断机组是否满负荷运行。

## 3. 系统组成与原理

### 3.1 水侧的冷量计算

水侧冷量可以用下面的近似公式估算：

```
Q(kW) ≈ 1.163 × 流量(m³/h) × 温差(℃)
```

其中 1.163 来自水的密度和比热容，只在常温附近误差很小。

**例：** 冷冻水流量 200 m³/h，供回水温差 5 ℃，则冷量约为 1.163 × 200 × 5 ≈ 1163 kW。

### 3.2 空气侧的显热计算

空气显热可以用近似公式：

```
Q_显(kW) ≈ 1.2 × 风量(m³/s) × 温差(℃)
```

其中 1.2 近似为空气密度与比热容的乘积。

### 3.3 湿空气的几个参数

| 参数 | 含义 | 与控制的关系 |
| --- | --- | --- |
| 干球温度 | 普通温度计测得的空气温度 | 最常用的温度控制量 |
| 湿球温度 | 湿纱布包裹的温度计测得的温度，受蒸发影响 | 反映空气的"可蒸发能力"，与冷却塔相关 |
| 露点温度 | 空气冷却到开始凝结水时的温度 | 判断是否会结露，是数据中心防凝露的关键 |
| 焓值（kJ/kg） | 空气的总能量，包括显热和潜热 | 新风与回风混合时，用焓值判断哪种模式更省能 |

> [!NOTE]
> 露点和相对湿度不是同一个概念。相对湿度随温度变化，而露点反映空气中水蒸气的绝对含量。同一个露点下，温度越高，相对湿度越低。

### 3.4 相似定律

水泵和风机的性能遵循相似定律（近似关系）：

| 参数 | 与转速的关系 |
| --- | --- |
| 流量 Q | 正比于转速 N |
| 压头或静压 H | 正比于转速的平方 N² |
| 功率 P | 正比于转速的立方 N³ |

**这意味着：** 转速降到 80 % 时，功率约降到 0.8³ ≈ 51 %。这就是变频水泵和风机节能的理论基础。

> [!IMPORTANT]
> 相似定律是近似关系，实际系统还受管网阻力、效率曲线和电机特性影响。选型和调试必须以厂家的性能曲线为准。

## 4. 控制逻辑

理解热力学基础之后，控制逻辑会更清楚：

1. 控制器采集温度、流量、压差等信号。
2. 根据显热或冷量公式，判断当前负荷。
3. 决定增减冷机台数、调整水泵转速或阀门开度。
4. 若需要除湿，还要判断露点，避免送风温度低于露点导致表面结露。

## 5. 常见故障与排查

| 现象 | 可能原因 | 排查顺序 |
| --- | --- | --- |
| 计算出的冷量明显偏大或偏小 | 流量计系数错误、温度传感器偏差 | 先核对温度传感器，再核对流量计安装位置和系数 |
| 水泵降速后功率下降不明显 | 系统压差未随转速同步变化，或电机效率低 | 检查压差设定、泵的性能曲线与实际工况 |
| 天花板或风管表面结露 | 表面温度低于空气露点 | 检查送风温度、露点传感器和保温层 |

## 6. 小结

- 温度只说明冷热程度，能量要用流量和温差共同计算。
- 显热和潜热要分开看，空调既要降温也要除湿。
- 露点是防凝露的关键参数。
- 水泵和风机的功率随转速的立方变化，这是变频节能的核心。
