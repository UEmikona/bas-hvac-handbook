# BA 与暖通知识手册

> 面向楼宇自动化（BA）、暖通空调（HVAC）与数据中心基础设施的开源学习手册。
> 每个设备和控制逻辑，我们都尽量讲清楚：**它是什么，更重要的是，它为什么存在。**

---

## 为什么做这个手册

入门这个领域时，常见的困难是资料零散：很多内容只讲一个设备或一个模块，学员记住了步骤，却说不清模块之间的关系。

这本手册想做的事情很简单：

- **由浅入深。** 从理论到设备，从设备到系统，从系统到控制与运维，逐步搭建知识体系。
- **讲清原因。** 每章都有"为什么这样设计"一节，回答设备为什么存在、不这样做会怎样。
- **公开可核查。** 数值有来源，不确定的内容会标注，欢迎任何人指出错误。

完整的愿景和编写原则见 [愿景与编写原则](docs/00-导读/01-愿景与编写原则.md)。

## 组织方式

本手册按两条主线梳理知识：

- **能量流**：冷量或热量从哪里产生、如何输送、在哪里被消耗。对应 `4-能量流/`。
- **信息流**：系统如何感知、通信、决策、诊断。对应 `2-感知与执行/`、`3-通信与数据/`、`5-控制策略/`、`6-调试与运维/`。

两条主线的交汇处，就是 BA 控制逻辑：它读取能量流的状态，并决定能量流的走向。

```
docs/
├── 00-导读/           愿景、使用方法、学习水平与进阶路径
├── 00-学习路线.md     全部章节的顺序、篇幅与预计时间
├── 1-基础理论/        热力学、流体、反馈控制等前置知识
├── 2-感知与执行/      传感器、执行器、水泵与风机变频
├── 3-通信与数据/      通信协议、变化值上报、点表设计
├── 4-能量流/          冷源、水系统、空气侧、末端与液冷
├── 5-控制策略/        控制序列、设定值复位、冷站群控
├── 6-调试与运维/      调试验收、故障诊断、能效与运维记录
└── 附录/              知识网络、知识地图、术语表、环境参数、标准索引、排版规范
```

## 每章的固定结构

| 模块 | 回答的问题 |
| --- | --- |
| 一句话概括 | 本章要解决什么问题 |
| 核心概念 | 这是什么 |
| 为什么这样设计 | 为什么需要它，不这样做会怎样 |
| 系统组成与原理 | 能量或信号如何流动 |
| 控制逻辑 | 系统如何被监控和调节 |
| 常见故障与排查 | 出问题时沿哪条逻辑链查 |
| 自测问题 | 学完能否独立回答 |

遇到较抽象的概念时，章节中会有一个 💡 类比框，帮助入门理解。类比只用于建立直觉，不能替代严格定义。
